由本机 LibreOffice 完成转换，保留原排版（扫描件会把页面作为图片嵌入）。比纯前端的「转 Word」质量高得多。当前支持 Word / PPT；高保真 Excel 不可用（请用「转 Excel」的文字版）。
怎么启动本机转换服务？
双击运行 server/start.bat（需已安装 Node.js 与 LibreOffice），保持窗口开启后刷新本页。
通过重新渲染页面压缩体积，对扫描件/图片型 PDF 效果明显；文字型 PDF 会被转为图片。
拖动下方缩略图调整页序（也可点“← / →”微调），然后点“开始处理”生成新 PDF。选定多个 PDF 时，各文件都按同一页序重排。
加密/解密由本机 Python（pypdf）处理，不上传。需先启动本机增强服务（server/start.bat）。
隐私：所有 PDF 都在你的浏览器本地处理，不会上传。文件较大时处理较慢，请耐心等待。
