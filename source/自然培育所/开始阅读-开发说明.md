# 自然培育所 · Nature Lab —— 开发包说明

> 版本 **v2.0** ｜ 纯前端（HTML + CSS + 原生 JS），无框架、无构建工具、无后端、无网络请求
> 解压即用，双击 `2-直接打开游戏.bat` 就能玩
> v2.0 新增：本地多用户档案、PIN 隐私锁、存档校验与损坏自愈、自动化验收

---

## 一、这个包里有什么

```
自然培育所-开发包/
├─ 1-启动开发服务器.bat      ← 日常开发用这个（改完按 F5 刷新）
├─ 2-直接打开游戏.bat        ← 只想玩，不开发
├─ 3-构建单文件版.bat        ← 把源码压成一个 .html
├─ 4-运行自检.bat            ← 发布前跑一遍（需 Node 18+）
├─ game/                     ← 源码（在这里改）
│   ├─ index.html            入口，DOM 结构 + 弹窗
│   ├─ css/style.css         全部样式，2100+ 行
│   ├─ js/                   26 个模块，见下表
│   ├─ assets/sprites/       174 张图（76 阶段图 + 76 柔边图 + 场景底图）
│   └─ README.md             玩法、数值、机制的完整文档
├─ dist/
│   └─ 自然培育所-单文件版.html   全内联，可离线分发
└─ tools/
    ├─ build_single.py       单文件构建脚本
    └─ audit.mjs             自动化验收（58 项）
```

## 二、三种运行方式

| 方式 | 做法 | 适用 |
|---|---|---|
| **本地服务器**（推荐） | 双击 `1-启动开发服务器.bat`，自动开 `http://localhost:8080` | 开发调试。改完保存 → 浏览器按 F5 |
| **直接打开** | 双击 `2-直接打开游戏.bat`，走 `file://` | 快速验证。功能同样完整，但部分浏览器对 `file://` 的字体/存储策略更严 |
| **VS Code Live Server** | 用 VS Code 打开 `game/` 目录，装 Live Server 插件，右键 `index.html` → Open with Live Server | 有自动热重载，最舒服 |

> 需要 Python 3 才能用第 1 种方式；没有 Python 就用第 2 种，或装个 Live Server。

### 改代码前建议先读这三个

1. **`js/engine.js`** —— 所有数值计算都从这里走。`harvestValue()` / `seedPrice()` 是两个经济锚点，改收益别绕开它们。
2. **`js/data.js`** —— 加物种只改这里。注意 `yield.base` 要和经济公式配平，否则会出现「种一季必亏」。
3. **`js/ui.js`** —— 界面渲染 + `loop()` 主循环。`lightRefresh()` 每 0.4 秒跑一次，BGM 的昼夜/季节同步挂在这里。
4. **`js/account.js`** —— 存储命名空间。新增任何 localStorage 键前先看这里；必须用 `storeKey('xxx')`，否则会绕过用户档案隔离。

## 四、加一个新物种（最常见需求）

在 `js/data.js` 的 `SPECIES` 里加一项即可，UI 会自动出现：

```js
newname: {
  id: 'newname', name: '中文名', habitat: 'soil',   // soil/water/land/hive/dark
  difficulty: 2,                                     // 1–4 星，影响种子定价
  env: { temp: [18, 26], humid: [55, 75], light: [50, 80], soil: [45, 70] },
  fragility: 1.0,                                    // 越大越脆
  days: 14,                                          // 一轮大致天数
  nutrition: { n: 3, p: 2, k: 3 },                   // 氮磷钾偏好
  stages: [ /* 每阶段 { name, img, desc } */ ],
  facts: [ /* 科普问答 */ ],
  yield: { base: 2.5, unit: '株' },
}
```

图片放进 `assets/sprites/`，命名要和 `stages[].img` 对上（WebP 格式）。加完跑一下 `python tools/build_single.py` 重新打包单文件版。

⚠️ **平衡性自检**：新物种的 `yield.base` 要保证「收获价值 > 种子价」，否则玩家种一季净亏。参考现有 18 个物种的 `base` 区间是 1.5–3.4。

## 五、用户与档案（v2.0）

本作没有服务器，所以「用户管理」落地为 **本机多用户档案**，而不是账号密码登录。

- 入口：顶栏右上角头像（移动端只留头像）或「更多 → 设置 → 档案与用户」
- 每个档案独立：3 个存档位、偏好设置、新手教学进度、成就与图鉴
- 支持新建 / 切换 / 重命名 / 换头像 / 删除；删除会清空该档案的全部数据
- PIN：4–12 位数字，SHA-256 + 随机盐（无 WebCrypto 时回退 FNV 迭代哈希）；启动锁屏，连续失败 5 次冷却 30 秒
- **PIN 只是同机访问锁，不是加密**：能打开 DevTools 的人可以绕过。共用电脑请使用独立的操作系统账户
- 导出：单档案包 `naturelab-profile`、全档案包 `naturelab-bundle`；旧的裸存档 JSON 仍可导入到当前存档位
- 旧版 v1.x 数据：首次启动自动迁入默认档案「培育员」，原键删除，不丢档
- 存储布局：`naturelab.accounts.v1`（注册表）、`naturelab.account.current`、`naturelab.u<id>.*`（档案命名空间）

> 加载顺序很重要：`account.js` 必须**第一个**加载，因为其它模块的 localStorage 键都要经过 `storeKey()` 加档案前缀；`app.js` 必须**最后**加载。

## 六、构建单文件版

```bat
双击 3-构建单文件版.bat
```
或命令行：
```bash
python tools/build_single.py
```

脚本会：内联 CSS → 图片转 base64 → 按 `index.html` 里的 `<script src>` **实际顺序**拼接 JS → 输出到 `dist/`。
所以**新增 js 文件后，只要在 `index.html` 里加上 `<script src="js/xxx.js"></script>`，构建脚本会自动带上**，不用改脚本。

## 七、存档与调试

- 存档键：`naturelab.u<档案id>.save.v1.slot1..3`；档案注册表 `naturelab.accounts.v1`
- 自动备份：每 5 个游戏天一份，每槽最多 3 份；**主档损坏时自动回滚到最近备份并提示**
- 损坏原文会隔离到 `...save.v1.corrupt`，不会被直接丢弃
- 设置键：`naturelab.u<档案id>.prefs` / `.sound` / `.vol` / `.bgm` / `.bgmVol`
- 游戏内「存档」面板可**导出 / 导入 JSON**；「档案」面板可导出整个档案（含设置与教学进度）
- 控制台有用对象：`S`（当前存档）、`SPECIES`、`ACHIEVEMENTS`、`CLIENTS`、`EVENTS`、`S3`（3D 场景）、`NL`（档案层）

常用调试片段（F12 控制台粘贴）：

```js
S.coins += 99999; renderAll();            // 加钱
S.day = 21; lightRefresh();               // 跳到秋天
S.slots[0].plot.quality = 95; renderAll(); // 直接把品质拉满看 S 级
```

## 八、当前状态与已知边界

**已完成**：玩法闭环、经济平衡（18/18 物种单轮净利为正）、28 成就、5 章手账、3 槽存档 + v1→v2 迁移、无障碍（79 个按钮全带可读标签）、设置面板 8 项、数字飘字、屏幕震动、程序化 BGM（场景 × 四季 × 昼夜）。

**v2.0 新增**：本地多用户档案、PIN 隐私锁与启动锁屏、档案级导入导出、存档结构校验、主档损坏自动回滚、保存失败可见提示、全局异常兜底、弹窗焦点陷阱、窄屏滚动修复、58 项自动化验收。

**已知边界**：

- 美术是 AI 生成的写实图，风格统一但非手绘/3D 精修。要提升只能换素材。
- `js/ui.js` 3200+ 行偏臃肿，若继续长期开发，建议拆成 `ui-stage.js` / `ui-panels.js` / `ui-loop.js`。
- 本地档案不是网络账号：不能跨设备同步，也没有找回密码服务；换设备请导出档案包。
- PIN 不构成加密安全，只防同机误入。
- 单文件版约 19MB，主要是 174 张 WebP。若在意首屏，可按栖息地拆包懒加载。

## 九、浏览器要求

Chrome / Edge 90+、Firefox 90+、Safari 15+。
3D 场景需要 WebGL；不支持时自动降级为静态背景（按钮会置灰并提示），不影响玩法。

```bat
双击 4-运行自检.bat
```
