# 敲散 · 解压气泡（桌面开发包）

通勤解压小游戏：**敲击屏幕上的情绪气泡**，两三下碎裂，配合力度判定、COMBO 连击、
爆破字效、ASMR 音效与震动，全碎后生成可保存的「情绪消散卡」。全程离线、零依赖、无广告。

当前版本：v3.2（图鉴气泡 / 情绪天气 / 云榜单）

---

## 一、目录结构

```
├─ QiaoSan.html          单文件完整版（HTML+CSS+JS 全部内联，双击即玩）
├─ tools/
│   └─ build_single.py   把 src/ 重新内联成单文件版
├─ start-windows.bat     Windows 双击用默认浏览器打开
├─ start-mac.command     macOS 双击打开（首次可能需在"系统设置-隐私"放行）
├─ src/                  开发版（推荐在这里改代码）
│   ├─ index.html        页面结构
│   ├─ styles.css        全部样式
│   ├─ profile.js        本地多档案 / PIN / 导入导出
│   └─ app.js            游戏逻辑（IIFE 单模块，暴露 window.__YS 调试入口）
├─ electron/             Electron 桌面应用壳（可选，打成 exe / dmg）
└─ README.md             本文件
```

> `QiaoSan.html` 由 `src/` 构建生成。改代码请改 `src/`，然后执行 `python tools/build_single.py` 重新内联，不要手改单文件。

## 二、三种运行方式

| 方式 | 步骤 | 适合 |
|---|---|---|
| 浏览器直接打开 | 双击 `QiaoSan.html`（或用启动脚本） | 试玩、临时改 |
| 本地静态服务 | `npx serve .` 或 `python3 -m http.server` 后访问 | 开发调试（无 file:// 限制） |
| Electron 桌面应用 | 见下文「打包成 exe」 | 正式桌面产品 |

**注意**：file:// 协议下 localStorage 正常可用；如遇浏览器限制（部分浏览器对
file:// 限制存储），改用本地静态服务方式即可。

## 三、快速上手开发

1. 用 VS Code 打开本目录；
2. 改 `src/app.js` 顶部常量即可调整大部分手感，不用深入逻辑：

| 常量 | 位置作用 | 说明 |
|---|---|---|
| `THEMES` | 屏幕内容主题池（通勤烦事/内耗/虫子/图案/自定义…） | 每项 `items` 为内容池，`mode` 为渲染类型 `text/emoji/pattern/pic` |
| `PALETTE` | 气泡配色环 | `c1` 亮色 `c2` 暗色 `h` 色相 |
| `HARD` | 难度系数（easy 0.70 / normal 1.0 / hard 1.40） | 越大越难碎 |
| `MARKS` | 默认爆破字池 | 设置面板里可被用户自定义覆盖 |
| `MARK_SIZE` | 字效四档字号倍率 | small/m/l/xl |
| `DIFF` | 烦恼雨三档难度（速度 / 出怪 / 硬度 / 命数） | 对应悠闲 / 标准 / 狂潮 |
| `BG_SETS` / `BG` | 每档难度的背景主题轮换与配色 | 每升一层换一套 |
| `SHAKE_THR` | 摇晃触发阈值 | 仅 trigger=shake 时使用 |
| `PHRASES` | 结算正向短句池 | |

3. 调试：页面控制台里 `__YS` 暴露了 `{ S, motion, AU, buildRound, attack, finish }`；
   例如 `__YS.attack(200,400,1.0)` 直接模拟一次重击。

## 四、核心机制速查（改参数前先看这里）

- **状态机** `S.mode`：`intro（引导） → armed（待首击） → play → done（结算）`
- **力度估算** `estimatePower(e)`：
  - 移动端 = 接触面积 + pointer pressure + 敲击瞬间加速度计峰值 + 连击节奏；
  - 桌面端固定基准 0.84（约 2 击碎），`Shift+点击` 或鼠标右键 = 1.45（一击爆破）。
- **伤害**：`dmg = power × 0.61 ÷ 气泡hard值`；`power ≥ 1.4` 直接秒碎。
  累计 0.24 出裂纹 → ≥1 碎裂。
- **COMBO**：950ms 内连击累加，伤害每层 +5.5%，上限 10 层。
- **碎裂特效**：粒子（普通 22 / 重击 30，上限受低端机约束）+ 壳碎片 + 双冲击环 +
  全屏白闪 + 放射线 + 屏幕抖动 + WebAudio 合成音 + `navigator.vibrate`。
- **布局** `slotLayout(n)`：1 居中 / 2 并排 / 3–5 环形 / 6–9 三列网格。
- **渲染**：单 Canvas 2D，伪 3D 多层绘制（球面渐变 + 边缘暗环 + 视差 + 焦散反光 +
  双高光），DPR 上限 2；所有渐变/噪点贴图预渲染缓存。

## 五、v3.2 新增：图鉴气泡与情绪天气

### 图鉴气泡（真实水彩素材）

- 两套主题，共 20 张透明水彩素材，来自 `source/forest/assets`（pals / world / dgrefs）。
- 「森林伙伴」：狐狸、兔子、小鹿、猫头鹰、刺猬、松鼠、蜜蜂、蝴蝶。
- 「万物图鉴」：苹果、蛋糕、气球、小汽车、胡萝卜、篮球、蘑菇、浆果、星星、宝石、磁铁、盾牌。
- 素材由 `tools/build_gallery.py` 统一裁切到 192×192 透明 WebP（共约 154KB），生成 `src/gallery.js`。
- 气泡内按形状裁剪（星形/心形/六边/圆角/无形状均可），敲碎后残影、消散卡也同步。
- 单文件版由 `build_single.py` 自动内联为 data URI，双击仍可离线看图鉴。

### 情绪天气

- 依据**点击节奏**（5 秒滑动窗口的敲击速率）与**漏怪**推高「情绪值」，四阶切换：晴朗 → 阴云 → 落雨 → 雷暴。
- 每阶带滞回与 2.4 秒最短停留，不会在阈值附近抖动；节奏慢下来会逐步降级。
- 视觉：天空压暗、云层飘移、雨丝、风偏、闪电（分叉路径 + 泛光）与全屏蓝白闪光。
- 声音：雨声（带通噪声）、风声（低通噪声）、雷声（低频噪声 + 60Hz 下滑），全部 WebAudio 实时合成。
- 雨滴与闪电不影响计分与命中，纯氛围；设置里可一键关闭（关闭后无环境音、无云雨闪）。
- 雨局 HUD 下方新增天气胶囊：图标 + 名称 + 情绪条。

## 六、v3.1 新增：烦恼雨（无尽下落模式）

### 玩法

- 开场选「烦恼雨」：烦恼从顶部不断落下，大小、形状、颜色、速度都不同，大的更耐敲。
- 敲碎得分，漏掉扣命；命用完结算。每敲碎 12 个升一层，下落更快、背景换色，每 3 层补 1 条命。

### 计分

- 每个 = 10 分 × 层数加成（+25%/层）× 连击加成（+8%/连，上限 14）× 尺寸系数（大 1.4 / 小 0.82）× 金色 3 倍。
- 爆裂：1.1 秒内连续敲碎，每到 3 的倍数额外 `+20 × 层数 × (连击/3)`，并触发全屏冲击环与横幅。
- 金色气泡出现率 6%，硬度低、分数 3 倍。

### 难度与背景

| 难度 | 下落 | 出怪间隔 | 硬度 | 同屏上限 | 命 | 背景轮换 |
|---|---|---|---|---|---|---|
| 悠闲 chill | 0.60× | 1.34s | 0.85× | 4 | 4 | 暮色 / 薄雾 / 极光 |
| 标准 normal | 1.00× | 0.98s | 1.00× | 6 | 3 | 赛博蓝 / 霓虹 / 深空 |
| 狂潮 frenzy | 1.58× | 0.72s | 1.22× | 7 | 2 | 熔岩 / 炼狱 / 毒沼 |

每层在同一难度的 3 套背景间轮换（`BG_SETS`），升级时重建背景画布。

### 排行榜与战绩卡

- 每个档案独立保存最近 20 局（`board`），按分数降序，可按难度筛选、可清空（两次点击确认）。
- 结算面板显示得分 / 破损 / 爆裂 / 层数 / 最高连击 / 本机名次。
- 「保存战绩卡」生成 900×1350 PNG，配色随当前难度与层级变化。

### 手感细节

- 下落时有横向摆动与轻微旋转，接近底部出现红色预警环与危险区提示。
- 开设置面板 / 弹窗 / 切后台自动暂停（`isPaused()`），不会在菜单里被扣命。
- 雨局命中判定半径放大到 1.34r，快速下落时更好点。
- 调试入口新增 `__YS.startRain / spawnRain / finishRain / makeRainCard / openRank`。

## 七、v3.0 能力（形状 / 动画 / 档案）

### 形状与大小

- 形状：圆形、圆角、六边形、星形、心形、无形状（只保留内容与一层淡底）。
- 大小差异：一致 / 轻微 / 明显。布局会按差异值缩小基准半径，避免大球互相挤压。
- 所有形状共用同一套球面渐变、边缘暗环、高光与裂纹绘制，不是简单换一个轮廓。

### 入场动画

- `mix` 随机：每颗气泡随机得到飞入 / 飘入 / 落入 / 弹出，方向、延迟、时长都不同。
- 单项模式可固定一种动画；「无」适合截屏与低动效偏好。
- 入场期间不做命中判定（透明度 < 0.45 时不可点），避免“看不见就被敲碎”。

### 破裂效果

- 碎裂：玻璃片 + 白闪 + 双层冲击环，最接近原版手感。
- 炸裂：更多碎片与放射线、三层冲击环、更大面积与屏幕震动。
- 烟雾：柔和色雾 + 少量碎片，轻而闷的“啵”。
- 颜色取气泡自身的亮色/暗色与补色，随机混合，不再固定白色。

### 本地多档案

- 右上角头像进入「我的档案」：改名、换头像、新建、切换、删除。
- 每个档案独立保存全部设置、局数、敲碎数与最高 COMBO。
- 可选 4–12 位 PIN：SHA-256 + 随机盐，启动锁屏，5 次失败冷却 30 秒。
- 支持导出 / 导入档案 JSON；清除数据会删除该档案命名空间下的全部键。
- 旧版 `yt_*` 键首次启动自动迁入默认档案，不丢设置。

## 八、打包成桌面应用（Electron，可选）

```bash
cd electron
mkdir app
cp ../src/index.html ../src/styles.css ../src/app.js ../src/profile.js app/
npm install          # 首次较慢（下载 Electron 运行时）
npm start            # 直接运行
npm run dist         # 产出安装包：dist/ 目录下 win nsis+portable / mac dmg / linux AppImage
```

窗口默认 480×820（竖屏手感），可拖拽调整；F5 刷新、F12 开发者工具。
想默认全屏：在 `main.js` 的 BrowserWindow 参数里加 `fullscreen: true`。

## 九、微信小程序 / H5 移植备注

- 敲击：小程序用 `bindtouchstart`（`e.touches[0]` 取坐标），力度可用
  `wx.onAccelerometerChange` 采样敲击瞬间的震动峰值（对应本版 `motion.peak` 通道）。
- 震动：`navigator.vibrate` → `wx.vibrateShort({type:'light'})`。
- 声音：WebAudio 合成在部分安卓 WebView 有延迟，建议把 `AU` 三音色换成预生成音频文件。
- 页面隐藏暂停：`wx.onAppHide/onAppShow` 对应现有 `visibilitychange` 逻辑。
