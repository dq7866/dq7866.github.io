## 2. 需求逐项落地

### 2.1 形状：从「只有气泡」到六种

- 新增 `shapePath()` 统一路径：圆形、圆角方形、六边形、五角星、心形。
- 新增「无形状」：不画外壳，只保留内容与一层很淡的暗底，文字/图案仍然可读。
- 所有形状共用球面渐变、边缘暗环、内壁厚度、外描边、顶部高光、裂纹裁切与悬停描边，不是简单替换轮廓。
- 命中判定按形状半径计算；入场未完成（透明度 < 0.45）时不可点击，避免“看不见就被敲碎”。
- 消散卡同步使用当前形状，保持游戏内与分享图一致。

### 2.2 大小差异

- 新增三档：一致 / 轻微（±14%）/ 明显（±30%）。
- 布局按差异值缩小基准半径（`fit = 1/(1+v*0.55)`），大球不会互相挤压。
- 每颗气泡的缩放因子在回合开始时固定，窗口缩放不会跳变。

### 2.3 入场与破裂动画

- 入场五种：随机 / 飞入 / 飘入 / 落入 / 弹出；随机模式为每颗独立抽取方向、延迟（0–0.12s）与时长（0.42–1.0s）。
- 飞入从左右屏外进入并带旋转；飘入从下方缓慢上浮；落入从上方下落；弹出用 `easeOutBack` 做回弹。
- 破裂三种：
  - 碎裂：玻璃片 + 双层冲击环 + 白闪，接近原版。
  - 炸裂：44 片碎片、12 条放射线、三层冲击环、更大白闪与屏幕震动。
  - 烟雾：16 团色雾 + 少量碎片，柔和扩散。
- 颜色取自气泡亮色、暗色与补色，随机混合；冲击环面积随气泡半径与破裂类型变化。
- 新增烟雾粒子类型（径向渐变、上升、膨胀），与碎片/火花分开更新。

### 2.4 设置面板宽度

- 桌面：`width:min(460px, calc(100vw - 28px))`，水平居中，四角 24px 圆角，底部 18px。
- 窄屏（≤560px）：恢复全宽底部抽屉，保留移动端手感。
- 实测 1280px 视口下面板宽 460px、左边距 410px，不再随页面宽度拉伸。

### 2.5 关于 / 帮助 / 用户管理

- HUD 新增「我的档案」与「帮助」按钮，设置面板底部也提供入口。
- 帮助：玩法、桌面快捷键、设置项说明、常见问题。
- 关于：版本 3.0、更新日志、隐私与数据、适龄提示、健康游戏忠告、制作信息。
- 档案：新建/切换/改名/换头像/删除、PIN 设置与修改、立即锁定、统计、导出/导入 JSON、清除全部数据。

### 2.6 新玩法：烦恼雨（无尽下落 + 难度 + 排行榜）

原版只有“一圈固定气泡”的单局玩法，节奏单一、没有分数与层级。v3.1 新增第二种玩法，两种模式共享同一套形状/破裂/音效系统。

- 开场即可选「静心一轮 / 烦恼雨」，下方直接切悠闲/标准/狂潮；设置面板也有同样两项，且雨局进行中修改会被拒绝并提示。
- 下落：每颗气泡独立速度、摆幅、频率、颜色、尺寸、形状（形状设为「随机」时每颗都可能是圆/圆角/六边/星/心）。
- 生命与层级：漏掉一个扣一条命，命归零结算；每 12 个升一层，速度 +6.2%/层、同屏上限递增、每 3 层补 1 条命。
- 计分：基础分 × 层数加成 × 连击加成 × 尺寸系数 × 金色倍率；1.1 秒内连敲 3/6/9… 触发「爆裂」额外加分 + 全屏冲击环 + 横幅。
- 反馈：危险区渐变 + 虚线、临掉红环、+分数飘字、层级/爆裂横幅、升级音效、金色气泡专用配色与 3 倍分。
- 结算：得分、破损、爆裂、层数、最高连击、本机名次，可存 900×1350 战绩卡，可进排行榜。
- 排行榜：本机、按档案隔离、最多 20 局、按分数降序、按难度筛选、两次点击清空。
- 背景：三档难度各三套主题（暮色/薄雾/极光、赛博蓝/霓虹/深空、熔岩/炼狱/毒沼），升级时重建背景画布；四类装饰（网格/星点/光斑/飞燼）区分质感。
- 暂停：设置面板、任何弹窗、切后台都会暂停推进，避免在菜单里被扣命。

## 3. 用户体系设计

纯离线游戏没有服务器，因此用户管理落地为**本机多档案**：

```text
qs.accounts.v1        档案注册表
qs.current            当前档案 id
qs.u<id>.yt_*         每个档案独立的设置与统计
```

- 每个档案独立保存：主题、数量、形状、大小差异、入场、破裂、音效、震动、字效、贴图、局数、敲碎数、最高 COMBO。
- 旧版 `yt_*` 键首次启动自动迁入默认档案，原键删除，不丢设置。
- PIN：4–12 位数字，SHA-256 + 随机盐（无 WebCrypto 时回退 16000 轮 FNV），5 次失败冷却 30 秒。
- **PIN 是访问控制，不是加密**：数据在 localStorage 中并非密文；共用电脑请使用独立系统账户。
- 忘记 PIN 无法找回，只能清除该档案数据（锁屏页有明确说明与二次确认）。

### 2.8 情绪天气（根据点击分析）

- 情绪值 = 5 秒滑动窗口的敲击速率（权重高）+ 漏怪累积（权重低），平滑后映射到四阶天气。
- 四阶：晴朗（无云）→ 阴云（云层 + 轻风）→ 落雨（雨丝 + 风声）→ 雷暴（雨 + 闪电 + 雷声）。
- 滞回 + 2.4 秒最短停留，避免阈值抖动；停手几秒自动回落。
- 视觉：天空压暗、云层飘移、斜雨、风偏、分叉闪电与蓝白闪光；纯氛围，不影响命中与计分。
- 声音：雨声（带通噪声）、风声（低通）、雷声（低频噪声 + 70→34Hz 下滑），全部实时合成，无音频文件。
- HUD 下方新增天气胶囊（图标/名称/情绪条），设置可一键关闭。

### 2.9 本机榜 + 全球榜

- 排行榜分「本机榜 / 全球榜」，两边都可按悠闲/标准/狂潮筛选。
- 云榜为可选：设置里开启后，结算时向本站 `/api/rank` 提交昵称与成绩；默认关闭，关闭时零请求。
- 服务端（Pages Worker + KV）：昵称清洗、数值一致性校验、同 IP 同难度每分钟 1 次限流，每档保留前 50、展示前 20。
