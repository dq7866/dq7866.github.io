## 技术要点

1. **离线优先**：只有汇率刷新走网络；SW 只接管同源 GET。
2. **零依赖**：不加载 CDN；农历与 XLSX 均内联自写。
3. **同一套换算模型**：内置单位、自定义线性单位、批量换算、专业单位共用基准值算法。
4. **双语靠字典 + 运行时切换**：`nm()/t()` 两个函数贯穿导航与面板，切语言只重渲染，不刷新页面。

## 数据口径与来源

- 市制：1尺 = 1/3 m，1斤 = 500 g，1亩 = 666.67 ㎡（台斤、港斤单列）。
- 英制：1 in = 25.4 mm（定义值），1 lb = 0.45359237 kg。
- 原油：1 bbl = 42 US gal = 158.987 L；API = 141.5/相对密度 − 131.5。
- 硬度按 ASTM E140 近似值，仅适用钢材，±2 HRC。
- 农历：solarlunar（ISC）内联；汇率：open.er-api.com。
