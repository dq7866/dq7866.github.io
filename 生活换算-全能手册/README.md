线上位置：`https://<你的域名>/toolbox/units.html`

## V8.6 长表导航 + 打印整册

- **页内小节导航**：138/170 个表格模块（4 节以上）标题下方出现一排小节胶囊，点击平滑直达并在目标卡片上闪一圈描边；滚动时 IntersectionObserver 跟随高亮当前小节；配合页内筛选，被过滤掉的小节胶囊同步变淡。移动端胶囊条横向滑动，打印自动隐藏。

## 技术要点

1. **离线优先**：只有汇率刷新走网络；SW 只接管同源 GET。
2. **零依赖**：不加载 CDN；农历与 XLSX 均内联自写。
3. **同一套换算模型**：内置单位、自定义线性单位、批量换算、专业单位共用基准值算法。
4. **双语靠字典 + 运行时切换**：`nm()/t()` 两个函数贯穿导航与面板，切语言只重渲染，不刷新页面。

## 数据口径与来源
