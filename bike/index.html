怎么玩

📱 体感模式（手机横握）

  • 左右摆动手机 → 转向（左摆左转 / 右摆右转）
  • 车头向上扬 → 翘头（提速、赚技巧分）
  • 车头向下压 → 翘尾（急刹、快速降速）
  • 左手区 按住 → 刹车减速
  • 右手区 按住 → 加速

💻 键盘 / 触屏

  • ↑ / W 加速，↓ / S 刹车
  • ← → 或 A D 转向
  • Q 翘头，E 翘尾
  • 屏幕按钮：左下 ◀ ▶ 转向，中间翘头翘尾，右下 刹车 / 加速

🏁 规则

  • 跑完全程计时，越快越好
  • 路上捡金币，撞障碍会掉速
  • 金币攒够可解锁更好的车
