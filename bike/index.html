怎么玩

📱 体感模式（手机横握）

  • 左右摆动手机 → 转向（左摆左转 / 右摆右转）
  • 车头向上扬 → 翘头（提速、赚技巧分）
  • 车头向下压 → 翘尾（急刹、快速降速）
  • 左手区 按住 → 刹车减速
  • 右手区 按住 → 加速

💻 键盘 / 触屏

  • ↑ / W 加速，↓ / S 刹车
  • ← → 或 A D 转向
  • Q 翘头，E 翘尾
  • 屏幕按钮：左下 ◀ ▶ 转向，中间翘头翘尾，右下 刹车 / 加速

🌦️ 六条赛道与它们的脾气

  • 城市平路 ★ 缓弯宽敞，练手首选
  • 起伏乡道 ★★ 连续上下坡，下坡冲、上坡掉速（避震改装能缓解）
  • 盘山公路 ★★★ 急弯陡坡，最容易冲出路外
  • 峡谷窄道 ★★★ 路面只有一半宽、发夹弯连着来，几乎不容错
  • 雨天湿滑 ★★★ 轮胎打滑：转向会飘、刹车距离变长，早刹车慢给油
  • 风口风原 ★★★ 侧风周期把车推偏，必须反向压身才能走直线（看右上角风向标）

🏁 规则与成长

  • 跑完全程计时，越快越好；路上捡金币、躲障碍
  • 金币可以买新车、做改装升级（轮胎抓地 / 气动极速 / 传动加速 / 避震 / 刹车）
  • 骑行积累经验 → 等级提升（升级还送金币）→ 解锁更强的车，等级越高称号越响亮
  • 每日任务：每天 3 条，全部完成有额外奖励，金币攒得飞快
  • 月度赛季：每趟按成绩换赛季积分，达标领档位奖励，还能看本赛季排名
  • 开启云同步后：成绩进云端排行榜，还能和别人的幽灵车同场跑
