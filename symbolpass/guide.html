0先分清：你遇到的是哪一个？

手机上「语音」相关的失败几乎都是这两个原因之一，对号入座即可。

症状 A · 语音识别失败 / 点话筒没反应
原因：网页语音识别必须「联网 + 允许麦克风 + 安全的打开方式（https）」。手机上以文件方式打开时，浏览器一律禁止麦克风——这不是 App 坏了。
症状 B · 英文朗读不出声 / 读出来是中文腔听不懂
原因：手机系统里没装英文语音包。朗读用的是系统自带引擎，系统没有英文声音，它就读不出来或读不准。

1语音输入：首选「键盘听写」，立刻可用

这是手机上最可靠的语音输入方式：不依赖网页麦克风权限、不受打开方式限制、离线也能用。识别结果会直接打进输入框，之后的转换、符号、朗读照常工作。

1
点一下输入框，调出键盘随便点在「用中文说你要表达的意思」那个框里
2
按键盘上的话筒键iPhone：在键盘右下角、地球键旁边；安卓（Gboard / 搜狗 / 百度输入法）：在键盘顶部工具条或空格键旁。第一次会请求权限，允许即可
3
说中文，说完点一下键盘文字自动填进输入框 → 点「转换」
如果坚持要用页面上的话筒按钮，必须同时满足三条：用 Chrome（安卓）或 Safari（iPhone）打开、页面在 https 地址上、并且允许了麦克风权限。 以文件方式打开的本地页面三条都满足不了，所以必然失败。想真正做到这一步，可以看本文最后的「进阶：给页面一个 https 网址」。
如果你在微信 / QQ 里打开：内置浏览器的麦克风经常被宿主限制。点右上角「···」→「在浏览器打开」，换到系统浏览器再试。

2英文朗读：给手机装一次英文语音（只需一次）

装好之后，「朗读英文」「慢速朗读」「播放这句英文」就都能用了，完全不需要网络。

iPhone / iPad
  1. 设置 → 辅助功能 → 朗读内容 → 声音 → 英语
  2. 挑一个英文声音下载（例如 Samantha）
  3. 完全关掉本页再重新打开（语音列表要重启页面才会刷新）
  4. 检查手机左侧的静音拨键——它在静音档时，网页朗读可能一点声音都没有
Android
  1. 设置 → 系统 → 语言和输入 → 文字转语音输出（各品牌叫法略有差异，搜索「文字转语音」或「TTS」一定能找到）
  2. 引擎选「Google 语音服务」，点 安装语音数据，下载 English (United States)
  3. 完全关掉本页再重新打开
验证装好了没有：打开系统自带的「文字转语音」示例播放，或让助手（Siri / 小艺）用英语说句话。系统能出英文声，本页就能。

3万能后备：复制英文，换个地方读

一时装不了语音、或者设备就是不支持时，这条路永远走得通。

  1. 在结果卡点 「复制英文」；或直接长按那句英文，选择「复制」
  2. 粘到任何能出声的地方：微信输入框、备忘录 + 朗读、系统翻译 App、有道 / Google 翻译
  3. 让对方听，或把屏幕直接递过去——文字本身就能沟通

4一分钟自检清单

  • 键盘的话筒键能听写中文，识别结果进了输入框
  • 系统文字转语音里能听到英文示例
  • App 里点「朗读英文」有声音（不行就先完全关掉页面重开一次）
  • 「复制英文」后粘贴出来内容正确
  • 飞行模式下打开本页：符号、例句、给对方看 全部正常

5进阶：给页面一个 https 网址

只有这一步能解锁「页面上的话筒按钮」这种真正的网页语音识别。日常使用用不到它。

  • 放到任何静态网站托管上（GitHub Pages、Cloudflare Pages、对象存储 + CDN 都行），把本页所在目录整个传上去，用手机浏览器打开 https 链接
  • 本地局域网调试：电脑上起一个 http 服务并用手机访问，可以测朗读，但网页麦克风仍然不可用（http 不算安全上下文）。安卓 Chrome 可用 chrome://flags → unsafely-treat-insecure-origin-as-secure 临时放开，iPhone 无此选项
  • 发布时可以顺手加上 <meta name="apple-mobile-web-app-capable"> 等标签做成 PWA，手机上「添加到主屏幕」后就像一个原生 App

6离线使用建议

本页不依赖任何网络和第三方资源。把它和本排查页一起存在手机本地（文件管理器里点开，或「添加到主屏幕」），出国前关掉流量试一遍——只要第 4 节的清单全过，旅途中任何一条例句都能随时调出来。
